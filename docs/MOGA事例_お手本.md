# MOGA 事例のお手本：1つの大窓をどう組み立てるか

README（1章「曼荼羅64の決まり」、7章「数値化の例」）から読む、私自身の曼荼羅の事例です。
64の窓をどう使うかを、3つのお手本で示します。

| お手本 | 何が分かるか |
|---|---|
| 1. 大窓B 地域防災 × 防災士教本 | 1冊の教本の章を、8つの小窓にどう割り振るか |
| 2. 大窓H の「核」と「シナプス」 | 窓6・窓8の決まりを、1つの大窓でどう生かすか |
| 3. 大窓C と大窓F の連動 | 大窓どうしが、どう刺激し合うか（シナプス反応） |

どの大窓でも、**窓6＝そのテーマの「核」**、**窓8＝窓1〜7を結ぶ糸「シナプス」** です（2026-11-15 決定）。

## 1. 大窓B 地域防災（白石市の災害対応策：自治会活動）× 防災士教本（全31章）

| | | |
|:-:|:-:|:-:|
| 1 地震・火山・原発 | 2 風水害・土砂・火災 | 3 ドローン・ハザードマップ |
| **8 防災DX【シナプス】** | **B 地域防災** | 4 要配慮者を守る |
| 7 都市工学・ふるさと | **6 住民自治【核】** | 5 わが家の備え |

流れ：足元の危険を知る（1〜3）→ 人と家を守る（4・5）→ 住民自治が核（6）→ まちを作る（7）→ デジタルで全部つなぐ（8）

（自助）＝自分と家族で守る　（共助）＝地域で助け合う　（公助）＝行政・国が支える

| 小窓 | 防災士教本の章 | この小窓にした理由 |
|---|---|---|
| 1 地震・蔵王火山・原発事故に備える（自助・公助） | 15 地震の仕組みと被害／16 津波のしくみと被害／17 火山噴火のしくみと被害／24 地震に関する知見・情報 ＋ 原発 | 足元の揺れ、蔵王の火山、そして原発。自分の土地にどんな危険があるかを知ることが、すべての出発点だから |
| 2 風水害を重視した気象予報と土砂災害・火災対策（自助・公助） | 18 風水害と対策／19 土砂災害と対策／20 火災と防火対策／23 公的機関による予報・警報 | 近年の大きな被害は風水害が中心。予報・警報を自分で読み解き、早めに動く力を養うため |
| 3 ドローンとハザードマップで地区の危険と避難路を知る（共助・公助） | 25 被害想定とハザードマップ／26 避難と避難行動 ＋ ドローン | 地区の危険箇所と避難路を、空からの目と地図で「見える化」し、いざという時の道を決めておくため |
| 4 婦人防災を踏まえ、高齢者・障害者を緊急時に守る（共助・公助） | 7 災害医療／9 避難所運営と仮設住宅の暮らし／13 緊急救助技術を身につける | 災害で最も困るのは、自分で逃げにくい人たち。命を守る手当てと救助の技を身につけるため |
| 5 わが家の備え：耐震・ライフライン・交通（自助） | 3 身近でできる防災対策／4 耐震診断と補強／5 災害とライフライン／6 災害と交通インフラ | 自助の基本。家が倒れず、水・電気・道が止まっても暮らしを続けられる備えを、わが家から固めるため |
| **6 住民自治を基礎とする地区防災のあり方（共助）【核】** | 2 防災士の役割／8 行政の災害対応／11 地域の自主防災活動／12 災害とボランティア活動／14 防災訓練 | 地震も風水害も避難も、最後は「自分の地区で住民がどう動くか」に戻ってくる。だから住民自治を真ん中に置いた |
| 7 防災ビジネスを見据えた都市工学とふるさとづくり（共助・公助） | 1 近年の自然災害に学ぶ／10 災害復旧と支援制度／27 都市防災／29 企業防災と事業継続計画／30 災害と損害保険／31 地域の再建と復興 | 過去の災害に学び、復旧・保険・事業継続・復興まで見通して、災害に強いふるさとを設計する。防災を仕事として生かす視点もここに |
| **8 防災DXで地域防災と防災庁をつなぐ（自助・共助・公助）【シナプス】** | 21 災害情報の発信と入手／22 災害と流言・風評／28 災害と危機管理 ＋ 防災DX・防災庁 | 1〜7で集めたもの（気象予報、ドローンの写真、ハザードマップ、要配慮者の名簿など）は、デジタルでつながって初めて地区全体の力になる。大窓H（IT・AI）とも響き合う窓 |

章の数：4＋4＋2＋3＋4＋5＋6＋3＝31章（教本の全章）

- 数え方：課題型。教本を1章読み終えたら、その章が入っている小窓の課題を1つ「済み」にします。防災士の勉強が進むほど、大窓Bの青が濃くなります。
- 章の名前の出どころ：内閣府「防災スペシャリスト検討会」の資料に載っている『防災士教本』の目次（全31章）。教本は改訂されることがあるため、お手元の教本の版で章の名前や数が違うときは、お手元の教本を正とします。

## 2. 大窓H RUNTEQと高齢社会のIT・AI対応 の「核」と「シナプス」

| 小窓 | 題名 |
|---|---|
| 1 | RUNTEQ卒業（卒制5課題のLGTM） |
| 2 | MOGAの開発（本リリース→生涯開発） |
| 3 | 継続受講（Rails・JavaScriptを深める） |
| 4 | 情報セキュリティとホワイトハッカー（OWASP） |
| 5 | AIと協働する（出力を検証して使う） |
| **6** | **データ分析（8つの大窓の数字を読む）【核】** |
| 7 | Mac・ITの基礎力（CPお爺ちゃん＆プルラリティ探求） |
| **8** | **高齢社会のIT・AI支援と発信（学習ノート・ブログ）【シナプス】** |

- **6が核である理由**：MOGAの心臓は「現在地と現在値を数字で冷徹に見る」ことです。Hの6は、AからHまで全部の数字を読む窓です。つまり、MOGAというアプリそのものの働きを、使う人自身が行う窓です。
- **8がシナプスである理由**：Eの8（ブログでもの書きの自分を公表）、Gの8（作品集をブログで遺す）、Fの自分史、どれも最後は「発信する・遺す」に集まります。Hの8は、そのすべてを受け止めて世に出す出口です。1つの大窓の中だけでなく、大窓どうしをつなぐシナプスになっています。

**一言で：Hの6は「全体を読む目」、8は「全体をデジタル等により世に出す口」。**

## 3. 大窓C と大窓F の連動（シナプス反応）

**一言で：C は「お金の数字」、F は「時間と暮らしの舵取り」。分けて持ち、互いに刺激し合わせます。**

| | 大窓C 金融ジェロントロジーの深掘り（資産寿命をいかに伸ばすか） | 大窓F 私の現在・過去・未来（中長期の家政学と近未来予測） |
|---|---|---|
| 受け持つもの | お金の数字（収入・家計・資産・寿命まで持つか） | 時間と暮らし（過去をふり返り、今日を記録し、未来を逆算する） |
| 核（窓6） | AI株式投資とメタトレンド投資の実践 | 明日の君は、今日の君ではない（日々前進、毎日の変化を愉しむ） |
| シナプス（窓8） | 資産管理とセキュリティーの高度化 | 家政学に重点を置いた自分自身のKPIおよびBSCの策定 |

**どこで連動するか（しびれるところ）**

| 大窓C の小窓 | ⇄ | 大窓F の小窓 | つながり |
|---|---|---|---|
| 2 家計管理簿 | ⇄ | 5 MBAの基本から家仕事（家政学）の基本へ転換 | 家計簿の数字は、家政学（暮らしの経営）の一番の材料になる |
| 3 我が家のバランスシートの精緻化 | ⇄ | 7 退職時点の11の課題の進捗状況 | 我が家の資産と負債を、退職時に立てた課題の進み具合と並べて見る |
| 4 100歳までの資産寿命シミュレーション | ⇄ | 4 20年後・10年後・5年後の自分の姿を逆算して描く | 「お金はいつまで持つか」と「その時どう暮らしていたいか」を、同じ年表の上で逆算する |
| 1〜8 すべての数字 | ⇄ | **8 KPI・BSC（シナプス）** | F8 の物差し（KPI・BSC）が、C の数字（年金カバー率・固定費率・貯蓄率・資産寿命など）も点検する |

- C だけだと「数字は良いが、何のためのお金か」が見えなくなります。F だけだと「暮らしの夢はあるが、お金が続くか」が見えなくなります。2つを分けて持ち、F8 の物差しで C を点検することで、お金と暮らしが互いを確かめ合います。
- この連動（連関性）はとても深く、金融ジェロントロジーの研究分野でもあり、高齢社会における一大テーマです。
- 今は、私が2つの大窓を見比べて連動させています。窓どうしを画面の上でつなぐ仕組みは、将来の候補です（README 9章）。
